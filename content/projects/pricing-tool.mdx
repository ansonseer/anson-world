## What it is
A bilingual (EN/中文) receiving & pricing ledger built for a real two-store retail operation.
A pricing tool — **not a CRM**. The demo works; the code is public.

## What happened
The delivery failed. The client never adopted it. That sentence stays on this page unsoftened,
because how a builder handles a failed delivery tells you more than ten success cards.

## The post-mortem
The full write-up is coming. What's already true and stays true: the tool worked, the client was
real, and it was never adopted. I won't publish the *why* until I can tell it honestly — without
guessing at anyone else's reasons. What the failure already changed is visible elsewhere on this
site: every engagement since runs on milestone acceptance, where nothing counts as done until
real staff complete real operations with it.
