## What it is
Two connected pieces:

1. **Crew (the instrument).** A decision-record system: each significant decision is captured through a fixed intake (question, options, reasoning, choice), stored as markdown case law, and re-surfaced when a similar decision comes up. v2 rebuilt the memory layer; it's currently in a Tier-1 trial on my own decisions.
2. **crew-guardrails (the constraint layer).** A TypeScript policy engine that constrains *the AI* to protect the user — exactly four policies: crisis-safety, anti-sycophancy, anti-dependency, consent-boundary. Zero runtime dependencies, 26 tests green.

## What's real and what's not
- Real: the vault, the scripts, the skill, the passing test suite.
- Not yet real: public release, and live integration — the guardrails layer currently talks to a typed mock of the partner engine (Ackem); real wiring waits on their hook implementation. Stated exactly so.
